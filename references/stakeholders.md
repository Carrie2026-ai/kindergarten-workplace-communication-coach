# 干系人分析

## 1. 权限
谁：
- 最终决定；
- 可以否决；
- 可以支持；
- 只是发表意见。

## 2. 核心任务
对方当前要为哪些结果负责？

幼儿园常见：
- 儿童安全；
- 班级稳定；
- 年级统一；
- 家长反馈；
- 公开活动；
- 园所检查；
- 教师团队协作；
- 课程质量。

## 3. 接受新建议需要什么

可能需要：
- 儿童证据；
- 现成方案；
- 风险边界；
- 小范围试点；
- 不影响整体安排；
- 有明确复盘节点。

## 4. 不做心理猜测

不要把对方的拒绝直接归因于：
- 年龄；
- 性格；
- 嫉妒；
- 控制欲；
- “认知低”。

先看角色和任务。
