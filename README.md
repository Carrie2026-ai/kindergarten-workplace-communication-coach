# 幼儿园职场沟通与协作助手

一个专门面向幼儿园一线教师、教研组长和管理人员的 **职场沟通 Skill**。

它处理的不是泛泛的“高情商说话”，而是幼儿园里很具体的关系与工作问题：

- 想向领导提不同意见；
- 新老教师教育理念冲突；
- 主配班分工不清；
- 同事工作推诿；
- 教研会上意见不一致；
- 想推动新做法，但担心被认为“不服从安排”；
- 管理人员不知道怎样反馈教师才不容易引起防御。

## 核心特点

### 先判断风险，再给话术
不会默认建议用户“勇敢表达”。

先看：
- 谁有决定权；
- 权力差有多大；
- 用户这一轮能承受什么结果。

### 不给别人贴人格标签
不会因为一次冲突就断言：
- 领导控制欲强；
- 老教师思想落后；
- 同事嫉妒；
- 对方故意针对。

### 不追求一次“说服”
很多园所沟通真正值得争取的是：
- 一次小试点；
- 一个观察窗口；
- 一个更明确的分工；
- 一个继续沟通的机会。

### 提供可直接说出口的话
重点是：
- 怎么开口；
- 核心怎么说；
- 对方拒绝怎么办；
- 怎么收尾；
- 沟通后怎么跟进。

## 适用对象

- 一线教师；
- 主班 / 配班教师；
- 年级组长；
- 教研组长；
- 保教与教学管理人员；
- 园长和课程管理者。
